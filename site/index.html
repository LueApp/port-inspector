A website on its own cannot read your machine's open ports — the browser sandbox forbids it. Port Inspector uses a tiny read-only agent that listens on 127.0.0.1:8790 and serves the port list as JSON. This page reads that agent directly from your browser. Start it once and this page becomes a live dashboard.
